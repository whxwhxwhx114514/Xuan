🔍 什么是 Xuan？

Xuan 是一款 仿 iOS 设计风格 的 Android 应用管理工具，
帮助你轻松管理手机中的所有应用。

❄️

冻结/解冻

一键冻结无用系统应用，节省电量与内存

🗑️

卸载应用

Root 权限卸载顽固系统应用

📦

提取 APK

备份应用安装包到 Download/Xuan

🛑

强制停止

立即终止运行中的应用

🧹

清除数据

一键清除应用缓存和数据

⚡

Root 授权

为任意应用授予永久 Root 权限

📱 界面一览

状态栏

右上角显示 Root ✓ 或 无权限

搜索框

实时搜索应用名或包名

用户/系统

切换用户应用和系统应用

批量操作

多选后批量提取、卸载、冻结、清除

长按菜单

长按应用弹出 iOS 风格操作面板

详情页

查看版本、大小、安装时间等

⚙️ 功能详解

功能说明是否需要Root
启动打开应用❌
提取APK备份应用到 Download/Xuan/❌（系统应用需Root）
详情查看包名、版本、大小、时间❌
强制停止立即终止应用进程✅
清除数据清除应用所有数据✅
冻结禁用应用（pm disable）✅
解冻启用已冻结应用✅
卸载(Root)完全卸载系统应用✅
Root权限授予应用 Magisk Root✅
批量操作多选后批量执行部分需要

📥 安装步骤

1️⃣

下载 APK

获取 xuan.apk 文件

2️⃣

允许未知来源

设置 → 安全 → 允许安装未知应用

3️⃣

安装

点击 APK 文件安装

4️⃣

获取Root（推荐）

安装 Magisk 获取 Root 权限以解锁全部功能

⚠ 提示：冻结/解冻/卸载系统应用等功能需要 Root 权限。
无 Root 也可使用启动、详情、提取APK等基础功能。

🔨 从源码构建

# 环境要求: Android SDK (aapt, dx/d8, apksigner, zipalign)
# 进入源码目录
cd xuan_app

# 一键构建
bash build.sh

# APK 输出位置
/sdcard/Download/xuan.apk

构建脚本会自动完成：编译 → dex → 打包 → 对齐 → 签名

📂 源码结构

xuan_app/
├── AndroidManifest.xml     # 应用清单
├── build.sh                # 构建脚本
├── res/                    # 资源文件
│   ├── layout/             # 布局 XML
│   ├── drawable/           # 形状/背景
│   ├── mipmap-*/           # 图标
│   ├── values/             # 颜色/字符串/主题
│   ├── anim/               # 动画
│   └── xml/                # FileProvider
└── src/com/xuan/app/
    ├── MainActivity.java   # 主界面（~560行）
    ├── RootHelper.java     # Root工具类（~195行）
    └── AppInfo.java        # 应用信息模型
